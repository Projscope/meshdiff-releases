# Meshdiff Desktop: releases

Download the latest installer for Windows from the [Releases page](https://github.com/Projscope/meshdiff-releases/releases/latest).

Meshdiff Desktop is a free app for comparing versions of a 3D model (STL, OBJ, 3MF) and checking whether it will print. Your projects, model files and comments are stored on your own computer, and it works offline without an account.

**Team sync is optional.** If you sign in and connect a project to a team, the project's stats, comments and a fingerprint (SHA-256) of each model are shared with your team. Your model files are never uploaded.

This repository only hosts installers and update information. The app updates itself from here. The source code is not published in this repository.
